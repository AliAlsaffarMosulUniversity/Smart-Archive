# الأرشيف الذكي — نسخة تجريبية 0.2

تطبيق سطح مكتب عربي لفحص الوثائق واقتراح تصنيفها ثم نسخها إلى أرشيف محلي بعد المراجعة. لا يحذف المصدر ولا يرفع وثائقك إلى خدمة سحابية.

## التشغيل على Windows

1. فك ضغط المشروع كاملًا إلى مجلد قصير مثل C:\SmartArchive.
2. ثبّت Python 3.12 بنواة 64 بت من المصدر الرسمي، مع إضافة Python إلى PATH.
3. شغّل build_windows.bat. يتطلب البناء الأول اتصالًا لتنزيل المكتبات وقد يستغرق عدة دقائق.
4. عند نجاح البناء، افتح dist\SmartArchive\SmartArchive.exe. يلزم إبقاء بقية ملفات هذا المجلد بجانبه؛ ليس ملفًا منفردًا مستقلًا.
5. لإنشاء مُثبّت، ثبّت Inno Setup ثم افتح installer\SmartArchive.iss واضغط Compile. الخرج داخل release. ملف البناء يحاول ذلك تلقائيًا إذا توفر ISCC في PATH.

بديل: بعد تثبيت الاعتماديات شغّل python app.py أو run_windows.bat بعد بناء البيئة.

يوجد سير عمل GitHub Actions لبناء Windows وإرفاق المخرجات، لكنه لم يُنفذ ضمن هذه الجلسة ولا يوجد ملف EXE مبني في هذه الحزمة.

## الاستخدام

- اختر مجلد الأرشيف وأضف ملفات أو مجلدًا؛ يمكن سحب الملفات مباشرة للواجهة.
- اختر نتيجة من الجدول وراجع النص والأدلة والتنبيهات.
- صحّح الجهة والتاريخ والتصنيف والموضوع. الحقول لا تُحفظ كتصحيح للمقترح إلا عند الاعتماد.
- اختر ترتيب مجلدات السنة والتصنيف والجهة، واضغط «اعتماد ونسخ آمن».
- افتح تبويب البحث لتجد النصوص والبيانات وتفتح الوثائق أو تصدر CSV.
- التراجع ينقل النسخة المؤرشفة إلى recovery، ولا يزيل الأصل.
- لا تعدّل archive.sqlite3 يدويًا. انسخ مجلد الأرشيف كاملًا للنسخ الاحتياطي بعد إغلاق التطبيق؛ يتضمن النصوص المستخرجة والبيانات، وهو غير مشفر.

جرّب أولًا الملفين الاصطناعيين في samples.

## الدعم الفعلي

PDF نصي، DOCX، XLSX، PPTX، TXT وCSV بترميز UTF-8، وصور JPG/PNG/TIFF/BMP/WEBP عند توافر OCR. الصيغ القديمة DOC/XLS/PPT وHEIC غير مدعومة حاليًا. النصوص داخل صور Office والأشكال المجمّعة والملاحظات ليست مضمونة الاستخراج. ترقيم صفحات Word غير متاح. لا تنفذ وحدات الماكرو.

للصور يلزم تثبيت Tesseract مع بيانات ara وeng وإضافة مساره إلى PATH. لصفحات PDF المصورة يلزم أيضًا Poppler وأداة pdftoppm في PATH. لا تُضمّن هذه البرامج أو بيانات اللغة في الحزمة. راجع تراخيص موزّعيها قبل إعادة توزيعها.

مكون OCR يعمل محليًا مع تنبيه للمراجعة. تصحيح الميل وإزالة الضوضاء وتقسيم الكتب المتعددة لم تُنفذ في هذه النسخة. التواريخ المكتوبة بالكلمات أو الهجرية تحتاج إدخالًا يدويًا.

## الذكاء الاصطناعي الاختياري

النسخة تعمل بقواعد عربية دون نموذج. لتفعيل اقتراح دلالي، شغّل Ollama على جهازك وثبت نموذجًا مناسبًا للعربية ثم أدخل اسمه كما يظهر عندك واضغط اقتراح بالنموذج المحلي. الاتصال مقصور برمجيًا على 127.0.0.1:11434. أول تنزيل للنموذج يحتاج اتصالًا ومساحة وذاكرة بحسب النموذج.

يُرسل أول 24000 محرف إلى النموذج المحلي، ويُعرض اقتراحه منفصلًا؛ لا يُطبق تلقائيًا. لا يوجد نموذج أو وزن مدرج بالحزمة. لم يُختبر اتصال Ollama فعليًا في هذه الجلسة. تحقق من ترخيص النموذج ومتطلبات جهازك قبل استعماله.

## حدود النسخة

- القواعد ليست نموذجًا مدربًا، ولا توجد دقة إحصائية مثبتة أو درجات ثقة معايرة.
- التاريخ يتطلب تسمية صريحة مثل «التاريخ:» وتنسيقًا رقميًا ميلاديًا؛ قد يظل ملتبسًا ويجب مراجعته.
- الجهة تستخرج من حقول صريحة مثل «الجهة المصدرة:» أو «صادر عن:»، وتحتاج مراجعة في الترويسات غير الموسومة.
- لا توجد مراقبة مجلد، نقل للأصول، تصنيف تلقائي دون مراجعة، PDF للتقارير، أو تعلم من التصحيحات بعد.
- حد حجم الملف 200 MiB. التحليل يجري بالتتابع لتقليل ضغط الموارد؛ الإلغاء بعد الملف الحالي.
- العمليات المنقطعة تظهر pending في السجل وتحتاج فحص النسخة يدويًا؛ لا يوجد استئناف تلقائي كامل.
- لا يُضمن كشف جميع أشكال الكتب المتعددة أو اختلافات التواريخ والجهات.
- لا يوجد تشفير أو توقيع رقمي للمُثبّت في هذه المرحلة.

## الاختبار والبناء

python -m unittest discover -s tests -v

اختُبر المنطق على Linux بملفات اصطناعية. لا تعتبر النسخة جاهزة للإنتاج قبل اختبار Windows ووثائق عربية حقيقية متنوعة ومراجعة التراخيص. إصدارات الاعتماديات في requirements.txt نطاقات؛ احتفظ بنتيجة pip freeze للبناء الذي تتحقق منه لضمان قابلية إعادة الإنتاج.

## المكونات والتراخيص

مكونات مباشرة: Python، PySide6/Qt، pypdf، python-docx، openpyxl، python-pptx، Pillow، PyInstaller. OCR الاختياري: Tesseract وPoppler. النموذج الاختياري عبر Ollama. لا تتضمن هذه القائمة موافقة قانونية على إعادة التوزيع؛ يجب جمع نصوص التراخيص وإشعارات التبعيات من الإصدارات المثبتة، وتقييم شروط Qt والمكونات الموزعة قبل النشر التجاري. توزيع التبعيات في مجلد مستقل يساعد على فصلها ولا يحسم الامتثال تلقائيًا.

## الترخيص في إصدار 0.2

تجربة 30 يومًا من أول تشغيل لكل حساب Windows. عند انتهائها تتوقف واجهة العمل حتى إدخال رمز دائم موقّع رقميًا ومرتبط بمعرّف الجهاز. زر التفعيل متاح أثناء التجربة أيضًا. بيانات التجربة محمية بآلية Windows DPAPI ومكررة في سجل المستخدم؛ إرجاع الساعة يُرصد ضمن حدود الحالة المحلية. حذف الأرشيف لا يحذف حالة الترخيص، وإزالة البرنامج لا تعيد التجربة عادة.

التحقق محلي، ولا يوجد خادم للتحقق من الوقت أو إلغاء التراخيص. حذف الحالتين أو حساب مستخدم جديد أو تعديل البرنامج قد يتجاوز الحماية. لا تدّعي هذه النسخة مقاومة الكسر المتقدم. التفعيل الدائم لا يحذف ملفات المستخدم عند انتهاء التجربة. لا تضمّن أي مفتاح توقيع خاص في المستودع أو المُثبّت.

فُصلت أداة إصدار الرموز ومفتاحها الخاص في حزمة خاصة بالمالك. النموذج العام موجود فقط في licensing.py للتحقق من التوقيع. تغيير Windows قد يغير معرّف الجهاز.
