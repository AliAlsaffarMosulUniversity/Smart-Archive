# الأرشيف الذكي 0.3

تطبيق Windows عربي لأرشفة الوثائق. يتضمن نموذج فهم معنى متعدد اللغات وقراءة الصور العربية والإنجليزية داخل المُثبّت، ويعمل بعد التثبيت دون Ollama أو Python أو اتصال لمعالجة الملفات.

## الاستخدام

أضف ملفات أو مجلدًا، وراجع نوع الوثيقة والجهة والتاريخ، ثم أرشف ملفًا واحدًا أو المحدد أو الكل. الأصول تبقى محفوظة. إزالة ملفات الوارد تزيلها من القائمة فقط. حذف الأرشيف ينقل النسخ إلى سلة الاستعادة، ومنها يمكن استعادة المحدد. جميع عمليات الحذف الجماعية تعرض عدد الملفات وتطلب تأكيدًا.

يمكن تحديد عدة صفوف باستخدام Ctrl أو Shift أو زر تحديد الكل. الإعدادات تحتوي على مجلد الأرشيف وترتيب المجلدات والوضع الفاتح والداكن والتفعيل. عند التحديث من 0.2 اختر مجلد أرشيفك السابق من الإعدادات ليظهر السجل القديم. سجلات التراجع القديمة التي لا تحتوي مسار استعادة تحتاج استعادة يدوية من recovery.

## المعالجة المدمجة

- استخراج نصوص PDF وDOCX وXLSX وPPTX وTXT وCSV.
- OCR عربي وإنجليزي للصور وPDF المصور، باستخدام Tesseract ونماذج tessdata_fast المرفقة.
- تحويل صفحات PDF المصورة داخليًا بواسطة PDFium دون تثبيت Poppler.
- نموذج paraphrase-multilingual-MiniLM-L12-v2 بصيغة ONNX للتحليل الدلالي، وليس نموذج محادثة توليديًا. يقارن مقاطع النص بأوصاف أصناف الوثائق. يحلل حتى 8 مقاطع موزعة على الوثيقة، مع دعم العنوان إن توفر؛ لا يدعي فحص كل كلمة في الوثائق الطويلة.
- العنوان الصريح يدعم التصنيف، والحالات المتقاربة تحال للمراجعة. درجات التشابه ليست احتمالات صحة أو دقة علمية معايرة.
- استخراج الجهة والتاريخ ورقم الكتاب يبقى محافظًا ويحتاج المراجعة، خصوصًا مع OCR الضعيف والترويسات المركبة.

تدعم الصور JPG/PNG/TIFF/BMP/WEBP. الصيغ القديمة DOC/XLS/PPT وHEIC غير مدعومة. حد الملف 200 MiB. لا يوجد حذف للأصول أو تشغيل ماكرو أو إرسال وثائق لخادم. لا يضمن النموذج صحة كل تصنيف. ليس مخصصًا لاستخلاص قرارات إدارية دون مراجعة.

## التجربة والتفعيل

تجربة 30 يومًا من أول تشغيل لكل حساب Windows، وتفعيل دائم موقّع مرتبط بالجهاز. نظام التفعيل ومفتاحه العام لم يتغيرا عن 0.2، وأداة المالك السابقة متوافقة. التحديث لا يعيد مدة التجربة. حالة الترخيص محمية محليًا بـDPAPI ومكررة في سجل المستخدم، ولا تدعي مقاومة الكسر المتقدم. المفتاح الخاص لا يوجد في المستودع أو المُثبّت.

## البناء

Python 3.12 على Windows x64. شغّل build_windows.bat. تنزيل أدوات القراءة والنموذج يحدث في وقت البناء فقط. تحتاج شبكة لتنزيل الاعتماديات وملفات OCR والنموذج من مصادرها. الخرج dist/SmartArchive/SmartArchive.exe ويتطلب بقية المجلد. مُثبّت Inno Setup في release عند توفر المترجم. سير العمل Windows في .github ينفذ بناء واختبارات محرك OCR والنموذج والواجهة والنسخة التنفيذية المجمعة.

الاعتماديات في requirements.txt. أدوات التحضير في tools. فحوص الاختبار:

python -m unittest discover -s tests -v

## التراخيص والخصوصية

تتضمن الحزمة ملفات إشعارات OCR والنموذج. أصل النموذج sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2، وتحويل ONNX من Xenova. الترخيص Apache-2.0. أداة Tesseract من توزيعة Windows المتاحة عبر UB Mannheim/releases، وبيانات اللغة من tesseract-ocr/tessdata_fast. PDFium ومكتبات Python وQt لها إشعارات وتراخيص مستقلة يجب الحفاظ عليها ومراجعتها قبل التوزيع التجاري. البيانات والفهرس المحلي غير مشفرين، لذا احفظ مجلد الأرشيف في مكان مناسب وصلاحيات مناسبة. لا توجد خدمة سحابية للوثائق في هذا الإصدار.
